# Orbit Hopper

A roguelike planet-hopping shooter that runs in the browser. Start at the neutral hub, chart a route through four rival factions, recruit a squad, fit out your ship, and destroy two faction flagships to win.

## Play

**[Play in your browser](https://manlymanataur.github.io/orbit-hopper/)**

Or download the repository and open `index.html` in any modern browser. There is no build step and no dependencies.

## Controls

| Key | Action |
| --- | --- |
| W A S D / arrows | Walk around a planet, or steer while flying |
| Space | Hold to charge, release to launch off a planet |
| B | Build while landed on a planet |
| Q | Order your squad (needs Squad tactics) |
| Shift | Dash in flight (needs Phase drive) |
| Esc / P | Pause |
| M | Mute |

Permanent hangar upgrades are saved in your browser's localStorage.
